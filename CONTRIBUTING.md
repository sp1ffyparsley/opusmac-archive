# Continuing this archive

Fork the repository and start with AGENTS.md and docs/STATUS.md. There is no active maintenance commitment or request for autonomous development. A fork can use and modify the independent source under LICENSE; preserve notices and distinguish your changes from this archived snapshot.

Before proposing a change, reproduce the problem with synthetic data, identify the canonical implementation owner, add focused tests and report platform limits. Never open a public issue with a private profile or log. Read SECURITY.md first. A new feature needs real verification, not placeholders, mock success or a claim of proprietary-product parity.
