# Product boundary

Independent dual-pane file manager built with .NET 8 and Avalonia. Real directory entries and canonical operation services own behavior. No commercial Directory Opus installation is required or bundled.

File mutation goes through FileOperationService. Indexed search uses the optional independent companion protocol, never the commercial database. An unavailable provider is visible rather than simulated. Exact proprietary behavior, physical Mac execution and Finder replacement are unverified; consult the root documentation.
