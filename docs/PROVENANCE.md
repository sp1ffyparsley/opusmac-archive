# Source provenance and publication boundary

The owner retired this independently authored experiment on November 13, 2026 and authorized public source publication. The original local archive is preserved privately. This repository starts from a new Git history containing selected source, tests, build tools and rewritten public documentation only.

This is not original or officially licensed proprietary product source, not a binary decompilation converted into a complete Mac port, and not an official vendor release. Product names describe compatibility goals only. No claim of complete behavioral or visual parity is made.

Copyright attribution uses the owner's public GitHub identity. Independent project source remains under the MIT license already declared by the archived project. Third-party package code is not relicensed by that declaration; consult pinned package metadata and retain required notices if distributing binaries.

Privacy changes in the public snapshot are deliberately separate from product work. Private prompts, machine paths, account identifiers and runtime state are omitted; documentation has been written for an unknown contributor instead of the original workstation. Synthetic test paths and loopback protocol fixtures remain where needed for repeatability. No historical private Git objects, chats, screenshots or runtime databases were uploaded.

All binaries, test receipts and benchmark statements must be tied to the source revision actually used. Old local packages are not releases of this public commit. Physical Apple Silicon execution and platform integration remain unverified unless a future maintainer supplies fresh evidence.
